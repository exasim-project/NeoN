\doxysubsection{Detailed Description}
A class for the representation of a symmetric 3x3 tensor. 

Upper-\/triangle storage order\+: \mbox{[}xx, xy, xz, yy, yz, zz\mbox{]} i.\+e. data\+\_\+\mbox{[}0\mbox{]}=xx, data\+\_\+\mbox{[}1\mbox{]}=xy, data\+\_\+\mbox{[}2\mbox{]}=xz, data\+\_\+\mbox{[}3\mbox{]}=yy, data\+\_\+\mbox{[}4\mbox{]}=yz, data\+\_\+\mbox{[}5\mbox{]}=zz.
