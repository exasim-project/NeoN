\doxysubsection{Detailed Description}
Carries named field references for wall-\/function boundary conditions. 

Wall functions that need auxiliary fields (U, nu, near\+Wall\+Dist, omega, k …) look up what they need by name instead of accepting a fixed argument list. All fields are stored as non-\/owning const pointers; the caller is responsible for ensuring the lifetime of the referenced fields exceeds the context.
