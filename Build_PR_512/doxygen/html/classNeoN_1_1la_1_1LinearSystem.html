Detailed Description

template<typename ValueType, typename SystemMatrixType = CSRMatrix<ValueType, localIdx>, typename BoundaryMatrixType = COOMatrix<ValueType, localIdx>>
class NeoN::la::LinearSystem< ValueType, SystemMatrixType, BoundaryMatrixType >

A class representing a linear system of equations.

The LinearSystem class provides functionality to store and manipulate a linear system of equations. It supports the storage of the coefficient matrix and the right-hand side vector, as well as the solution vector.
