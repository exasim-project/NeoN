Detailed Description

Connectivity for locating points (e.g. particles) in an UnstructuredMesh and interpolating cell values to them, on the executor (CPU or GPU).

UnstructuredMesh stores cell and face geometry but not which faces belong to a cell or which points belong to a face. TrackingMesh adds exactly that, plus the tet base point of every face (for the tet decomposition used by point interpolation) and the periodic (cyclic) face pairing. It also keeps its own copy of the points on the executor, since UnstructuredMesh may hold them on the host only.

The geometry it does not own is read from the mesh, which must outlive it.
