19** The boundary view covers both physical and proc boundary faces in a single contiguous array.

42/* @brief Device-callable weight kernel for upwind interpolation.
43** Internal weight: 1 if flux >= 0 (owner upwind), 0 otherwise.
44** Physical boundary weight: always 1 (value comes from the BC, not interpolated).
45** Proc boundary weight: flux-sign, matching the coupled internal-face convention.
46*/
47struct UpwindInlineKernel
