\doxysubsection{Detailed Description}
Default \doxylink{classNeoN_1_1finiteVolume_1_1cellCentred_1_1GeometryScheme}{Geometry\+Scheme} kernel\+: computes weights, delta\+Coeffs, non\+Orth\+Delta\+Coeffs and the non-\/orthogonal correction vectors directly from the mesh geometry. 

Assumptions baked into this kernel (review L8)\+:
\begin{DoxyItemize}
\item delta\+Coeffs is the orthogonal inverse cell-\/to-\/cell distance 1/\texorpdfstring{$\vert$}{|}d\texorpdfstring{$\vert$}{|} (matches Open\+FOAM\textquotesingle{}s uncorrected\+Sn\+Grad); non\+Orth\+Delta\+Coeffs is the over-\/relaxed 1/(n.\+d) floored by non\+Orth\+Delta\+Clamp.
\item boundary weights are 1 (one-\/sided physical patches); processor weights are d\+N/(d\+O+dN).
\item processor-\/boundary delta\+Coeffs/non\+Orth\+Delta\+Coeffs use the face-\/normal-\/projected owner+neighbour distance (exact on orthogonal proc faces); the non-\/orthogonal correction is not applied at processor faces (see \doxylink{classNeoN_1_1finiteVolume_1_1cellCentred_1_1FaceNormalGradient}{Face\+Normal\+Gradient} docs).
\end{DoxyItemize}

Marked final to enable devirtualisation of the kernel calls in \doxylink{classNeoN_1_1finiteVolume_1_1cellCentred_1_1GeometryScheme_ab67d199285124264e5183829810892a3}{Geometry\+Scheme\+::update()}.
