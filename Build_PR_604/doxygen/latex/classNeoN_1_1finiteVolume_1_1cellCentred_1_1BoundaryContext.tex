\doxysubsection{Detailed Description}
Carries named field references for context-\/aware boundary conditions. 

Boundary conditions that need auxiliary fields (U, nu, near\+Wall\+Dist, omega, k …) look up what they need by name instead of accepting a fixed argument list. Volume fields cover wall functions; the surface-\/scalar slot carries the face flux phi consumed by flux-\/dependent BCs such as inlet\+Outlet. All fields are stored as non-\/owning const pointers; the caller is responsible for ensuring the lifetime of the referenced fields exceeds the context.
