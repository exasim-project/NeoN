Detailed Description

Carries named field references for context-aware boundary conditions.

Boundary conditions that need auxiliary fields (U, nu, nearWallDist, omega, k …) look up what they need by name instead of accepting a fixed argument list. Volume fields cover wall functions; the surface-scalar slot carries the face flux phi consumed by flux-dependent BCs such as inletOutlet. Plain scalar values (not fields) cover per-call solver state a BC needs but that has no field of its own, such as the current simulation time or timestep deltaT. All fields are stored as non-owning const pointers; the caller is responsible for ensuring the lifetime of the referenced fields exceeds the context.
