\doxysubsection{Detailed Description}
\doxylink{classNeoN_1_1la_1_1Solver}{Solver} for block-\/coupled linear systems that calls Ginkgo directly with zero-\/copy views. 

Unlike the free function la\+::solve() which deep-\/copies through \doxylink{namespaceNeoN_1_1la_ac19cc6fa4f17dd75962891309709bca8}{to\+CSR()} and \doxylink{classNeoN_1_1la_1_1LinearSystem}{Linear\+System}, \doxylink{classNeoN_1_1la_1_1BlockSolver}{Block\+Solver} wraps Block\+Matrix/\+Block\+Vector data directly into Ginkgo arrays and matrices without any intermediate copies.
