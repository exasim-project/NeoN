\doxysubsection{Detailed Description}
Device-\/safe view into an n\+Blocks x n\+Blocks dense coupling matrix. 

Represents the coupling between field components at a single CSR position (cell pair). Stored in column-\/major order\+: operator()(i, j) accesses values\mbox{[}i + j \texorpdfstring{$\ast$}{*} n\+Blocks\mbox{]}.
