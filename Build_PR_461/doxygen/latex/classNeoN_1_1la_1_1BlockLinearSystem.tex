\doxysubsection{Detailed Description}
Orchestrator that owns a block matrix, RHS, and solution vectors. 

Ties together \doxylink{classNeoN_1_1la_1_1BlockMatrix}{Block\+Matrix}, \doxylink{classNeoN_1_1la_1_1BlockVector}{Block\+Vector}, and Block\+Solve with expression-\/driven assembly using bdsl operators. Operators carry field names; \doxylink{classNeoN_1_1la_1_1BlockLinearSystem}{Block\+Linear\+System} maps names to block columns during assembly.
