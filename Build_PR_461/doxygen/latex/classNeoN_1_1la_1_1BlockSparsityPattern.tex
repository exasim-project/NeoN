\doxysubsection{Detailed Description}
Monolithic sparsity pattern expanded from a base per-\/block sparsity. 

Given n\+Blocks and a base sparsity (n\+Cells rows, base\+Nnz non-\/zeros), computes the expanded monolithic pattern with n\+Blocks\texorpdfstring{$\ast$}{*}n\+Cells rows and n\+Blocks\texorpdfstring{$^\wedge$}{\string^}2\texorpdfstring{$\ast$}{*}base\+Nnz non-\/zeros. The expansion only depends on n\+Blocks + base sparsity, so it is computed once at construction.
