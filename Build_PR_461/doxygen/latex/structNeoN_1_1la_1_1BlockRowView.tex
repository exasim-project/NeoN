\doxysubsection{Detailed Description}
Device-\/safe view into selected rows of a coupling matrix. 

Returned by Block\+Matrix\+View\+::row\+View(k, start\+Row, end\+Row). Represents a rectangular n\+Rows x n\+Blocks sub-\/matrix of the coupling matrix at CSR position k. The underlying column-\/major stride is n\+Blocks (the full coupling matrix height), so operator()(i, j) = values\mbox{[}i + j \texorpdfstring{$\ast$}{*} n\+Blocks\mbox{]}.
