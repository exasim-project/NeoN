\doxysubsection{Detailed Description}
A block-\/structured sparse matrix with shared sparsity across all blocks. 

Values are stored in monolithic CSR order\+: the n\+Blocks\texorpdfstring{$\ast$}{*}n\+Cells monolithic rows are laid out contiguously. Total values size is n\+Blocks\texorpdfstring{$^\wedge$}{\string^}2 \texorpdfstring{$\ast$}{*} nnz.
