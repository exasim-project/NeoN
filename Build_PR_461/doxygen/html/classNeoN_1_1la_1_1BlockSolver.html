Detailed Description

Solver for block-coupled linear systems that calls Ginkgo directly with zero-copy views.

Unlike the free function la::solve() which deep-copies through toCSR() and LinearSystem, BlockSolver wraps BlockMatrix/BlockVector data directly into Ginkgo arrays and matrices without any intermediate copies.
