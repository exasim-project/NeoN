Detailed Description

A flat vector storing nBlocks contiguous blocks of nCells scalars each.

Layout: [block0_cell0 ... block0_cellN, block1_cell0 ... block1_cellN, ...] Block I occupies data[I * nCells ... (I+1) * nCells).
