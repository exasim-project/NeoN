Detailed Description

Device-safe view into selected rows of a coupling matrix.

Returned by BlockMatrixView::rowView(k, startRow, endRow). Represents a rectangular nRows x nBlocks sub-matrix of the coupling matrix at CSR position k. The underlying column-major stride is nBlocks (the full coupling matrix height), so operator()(i, j) = values[i + j * nBlocks].
