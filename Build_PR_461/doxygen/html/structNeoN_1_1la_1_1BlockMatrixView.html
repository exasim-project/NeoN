Detailed Description

Device-safe view into the full block matrix structure.

Values are interleaved by CSR position: at each of the nnz non-zero positions, an nBlocks x nBlocks column-major coupling matrix is stored. operator()(k) returns the BlockView at CSR position k. rowView(k, startRow, endRow) returns a rectangular BlockRowView.
