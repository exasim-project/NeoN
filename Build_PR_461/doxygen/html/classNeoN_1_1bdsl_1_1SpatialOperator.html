Detailed Description

template<typename ValueType>
class NeoN::bdsl::SpatialOperator< ValueType >

Type-erased wrapper for block spatial operators.

Uses the Concept/Model pattern (like dsl::SpatialOperator) but with getFieldName() and block-aware implicitOperation signature.
