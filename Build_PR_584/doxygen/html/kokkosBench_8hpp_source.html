82// The GMG V-cycle bench: gmgPrecond.hpp's native V-cycle with its AMReX kernels and with
83// Kokkos twins -- a whole solver phase, so launch cost in a real hierarchy's shape.

85// The operator (diagonal source + face coefficients) and the rhs, all FP64 on one

100 // The cycle shape, production's own struct: the bench measures the SAME knobs the
101 // preconditioner runs. Reduced precision, share_coeffs and aggLevel0Size are honoured by
102 // the kokkos_opt backend alone -- benchGmgVcycle refuses them elsewhere rather than
103 // reporting an fp64 timing under another label. `cycles` is unused here: benchGmgVcycle
104 // takes its own `iters`, so a batch's cycle count is the bench's, not the caller's.
