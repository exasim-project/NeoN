51// Matrix-free face-coefficient operator on one structured level: the mat-vec is Amul in pull
52// form against diag = alpha - (aE+aW+aN+aS+aT+aB); `alpha` is the diagonal SOURCE, and
53// upper[d]/lower[d] the HIGH/LOW face couplings -- pass the same fields for both if symmetric.
54
55// PROTOTYPE (C1): the `diag` argument is IGNORED -- both stencils recompute alpha - sum(faces)
56// inline, in that same association order (faceCoeffOp.cpp).
57
58// V types the flat Ginkgo vectors only, not the coefficients; V = float is a DEVICE path (the
59// host stencil is double) and the constructor rejects it on the host. Measurements:
60// report/blockamr-precision-measurements.md
