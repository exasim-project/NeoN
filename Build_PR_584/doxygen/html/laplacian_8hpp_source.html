18 * has no copy ctor) and must outlive every `+=`.
19 */

22public:
23
24 // `bcData` carries the INHOMOGENEOUS datum in its ghost layer (MLMG's setLevelBC
25 // contract); null means homogeneous. Geometry and the domain BCs arrive on the matrix.
26 explicit Laplacian(const amrex::MultiFab& gamma, const amrex::MultiFab* bcData = nullptr);

28 // Accumulates; the signature IS the contract, no concept. Holds no geometry and no bc --
29 // both are read off the system's matrix, so the operator has nowhere to keep a copy that
30 // could disagree with it. A non-periodic domain face keeps its REAL coefficient -- do NOT
31 // re-zero it to fold the BC here; the diagonal half is the consumer's, per level. `gamma`
32 // on such a face is the boundary cell's own, because the ghost beyond it is never filled.
33 // Only `upper[d]` is written when the matrix is symmetric, where `lower[d]` ALIASES it.
34 // Also writes the inhomogeneous `rhs -= aF*scale*g`, which no la:: consumer can produce.
35 // Tripwire:
36 // test_la_boundary_conditions.py::test_laplacian_writes_the_boundary_face_coefficient. Why, and
37 // the measurements: report/blockamr-linear-algebra-notes.md#laplacian-bcs
