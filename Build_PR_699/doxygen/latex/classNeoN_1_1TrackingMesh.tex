\doxysubsection{Detailed Description}
Connectivity for locating points (e.\+g. particles) in an \doxylink{classNeoN_1_1UnstructuredMesh}{Unstructured\+Mesh} and interpolating cell values to them, on the executor (CPU or GPU). 

\doxylink{classNeoN_1_1UnstructuredMesh}{Unstructured\+Mesh} stores cell and face geometry but not which faces belong to a cell or which points belong to a face. \doxylink{classNeoN_1_1TrackingMesh}{Tracking\+Mesh} adds exactly that, plus the tet base point of every face (for the tet decomposition used by point interpolation) and the periodic (cyclic) face pairing. It also keeps its own copy of the points on the executor, since \doxylink{classNeoN_1_1UnstructuredMesh}{Unstructured\+Mesh} may hold them on the host only.

The geometry it does not own is read from the mesh, which must outlive it.
