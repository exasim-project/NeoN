\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Value\+Type$>$\newline
class Neo\+N\+::\+Array$<$ Value\+Type $>$}
An executor-\/aware contiguous container for structural and indexing data. 

\doxylink{classNeoN_1_1Array}{Array} is intended for data that is primarily used as a generic collection, particularly for structural, indexing, or other non-\/arithmetic data.

Unlike \doxylink{classNeoN_1_1Vector}{Vector}, \doxylink{classNeoN_1_1Array}{Array} does not primarily model numerical quantities or provide vector-\/style arithmetic semantics. Use \doxylink{classNeoN_1_1Array}{Array} when the primary purpose of the data is storage and indexed access rather than numerical operations.
