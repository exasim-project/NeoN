\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Value\+Type$>$\newline
class Neo\+N\+::\+Vector$<$ Value\+Type $>$}
An executor-\/aware contiguous container for numerical data with vector-\/style arithmetic semantics. 

\doxylink{classNeoN_1_1Vector}{Vector} is intended for numerical quantities for which arithmetic operations on the elements or on the vector as a whole are meaningful.

\doxylink{classNeoN_1_1Vector}{Vector} provides operations for performing arithmetic on its stored values. Use \doxylink{classNeoN_1_1Vector}{Vector} when the numerical meaning of the data and its arithmetic operations are an important part of its interface.

For structural, indexing, or other non-\/arithmetic data, use \doxylink{classNeoN_1_1Array}{Array} instead.
