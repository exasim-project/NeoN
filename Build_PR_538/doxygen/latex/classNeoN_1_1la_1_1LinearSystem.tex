\subsubsection*{template$<$typename Matrix\+Value\+Type, typename System\+Matrix\+Type = CSRMatrix$<$\+Matrix\+Value\+Type, local\+Idx$>$, typename Boundary\+Matrix\+Type = COOMatrix$<$\+Matrix\+Value\+Type, local\+Idx$>$, typename RHSValue\+Type = Matrix\+Value\+Type$>$\newline
class Neo\+N\+::la\+::\+Linear\+System$<$ Matrix\+Value\+Type, System\+Matrix\+Type, Boundary\+Matrix\+Type, RHSValue\+Type $>$}
\doxylink{classA}{A} class representing a linear system of equations. 

The \doxylink{classNeoN_1_1la_1_1LinearSystem}{Linear\+System} class provides functionality to store and manipulate a linear system of equations. It supports the storage of the coefficient matrix and the right-\/hand side vector, as well as the solution vector.


\begin{DoxyTemplParams}{Template Parameters}
{\em Matrix\+Value\+Type} & The value type of the system and boundary matrix coefficients. \\
\hline
{\em System\+Matrix\+Type} & The sparse matrix type used for the system matrix (default\+: CSRMatrix$<$\+Matrix\+Value\+Type, local\+Idx$>$). \\
\hline
{\em Boundary\+Matrix\+Type} & The sparse matrix type used for boundary and off-\/diagonal matrices (default\+: COOMatrix$<$\+Matrix\+Value\+Type, local\+Idx$>$). \\
\hline
{\em RHSValue\+Type} & The value type of the right-\/hand side and boundary rhs vectors. Defaults to Matrix\+Value\+Type, but may differ (e.\+g. scalar matrix with \doxylink{classNeoN_1_1Vec3}{Vec3} rhs for segregated vector solves). \\
\hline
\end{DoxyTemplParams}
