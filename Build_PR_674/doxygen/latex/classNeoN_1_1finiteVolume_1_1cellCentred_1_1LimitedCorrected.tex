Computes the face-\/normal gradient of {\ttfamily vol\+Vector} into {\ttfamily surface\+Vector}. 

Processor-\/boundary contract\+: processor faces are treated like internal faces (the standard coupled-\/patch treatment), i.\+e. the gradient couples the owner cell with the true neighbour cell on the far side of the rank boundary. Schemes that apply a non-\/orthogonal correction (corrected, limited\+Corrected) apply it on processor faces as well. Scalar and \doxylink{classNeoN_1_1Vec3}{Vec3} fields receive identical treatment.
