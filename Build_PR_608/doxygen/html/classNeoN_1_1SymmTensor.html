Detailed Description

A class for the representation of a symmetric 3x3 tensor.

Upper-triangle storage order: [xx, xy, xz, yy, yz, zz] i.e. data_[0]=xx, data_[1]=xy, data_[2]=xz, data_[3]=yy, data_[4]=yz, data_[5]=zz.
