\doxysubsection{Detailed Description}
Integer types used throughout \doxylink{namespaceNeoN}{NeoN}. 

The following type aliases distinguish between different kinds of integer values\+:


\begin{DoxyItemize}
\item {\ttfamily label} identifies mesh entities (e.\+g. cell number and face number)
\item {\ttfamily local\+Idx} indexes data that is local to a process or execution space, such as arrays, views, and local graph structures.
\item {\ttfamily global\+Idx} identifies globally unique entities in distributed-\/memory computations.
\item {\ttfamily size\+\_\+t} represents sizes and counts (e.\+g. container sizes, iteration counts, and memory sizes) and should not be used to identify mesh entities.
\end{DoxyItemize}

The widths of {\ttfamily label}, {\ttfamily local\+Idx}, and {\ttfamily global\+Idx} depend on the compile-\/time configuration ({\ttfamily Neo\+N\+\_\+\+DP\+\_\+\+LABEL} and {\ttfamily Neo\+N\+\_\+\+US\+\_\+\+IDX}).
