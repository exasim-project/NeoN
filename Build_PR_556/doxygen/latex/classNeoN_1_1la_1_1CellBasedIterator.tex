\doxysubsection{Detailed Description}
Iteration strategy that traverses cells and their face stencils. 

Pre-\/computes a cell-\/centric connectivity table (\doxylink{structNeoN_1_1la_1_1CellBasedIterator_1_1CellBasedData}{Cell\+Based\+Data}) so that each cell can independently gather all face contributions during assembly, which is better suited for GPU-\/parallel execution than the face-\/based approach.
