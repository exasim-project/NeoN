\subsubsection*{template$<$typename Value\+Type, typename Index\+Type = local\+Idx$>$\newline
class Neo\+N\+::dsl\+::\+Fixed\+Value\+Constraints$<$ Value\+Type, Index\+Type $>$}
Post-\/assembly functor that pins a set of cells to prescribed values. 

For every constrained cell c\+: \doxylink{classA}{A}\mbox{[}c, j\mbox{]} = 0 for j != c (zero row off-\/diagonals) \doxylink{classA}{A}\mbox{[}j, c\mbox{]} = 0 for j != c (zero column in neighbour rows, rhs\mbox{[}j\mbox{]} absorbs the dropped term) rhs\mbox{[}c\mbox{]} = \doxylink{classA}{A}\mbox{[}c,c\mbox{]} \texorpdfstring{$\ast$}{*} value\mbox{[}c\mbox{]}

Pinning via both the row and column cut avoids large cancellation errors when pinned values are orders of magnitude larger than neighbouring unknowns. Off-\/rank coupling in off\+Diagonal\+Matrix is also zeroed for pinned rows.

Restricted to scalar Value\+Type\+: the segregated vector-\/solve path dispatches through \doxylink{structNeoN_1_1dsl_1_1PostAssemblyBase_af0170570aa68740698ac111b485cc18c}{apply\+Scalar\+Matrix()}, which this class does not implement.

mask\mbox{[}cell\mbox{]} != 0 marks a constrained cell; value\mbox{[}cell\mbox{]} holds its target. Both views are sized n\+Cells and must outlive the functor.
