51/* @class FaceToMatrixAddress
52 * @brief Stores the mapping between mesh faces and target matrix sparsity pattern,
53 * together with the three sparsity patterns (local CSR, boundary COO,
54 * nonLocal/processor-boundary COO).
55 *
56 * Based on a given computational mesh this class stores a mapping for a consistent
57 * iteration procedure for matrices which share the same sparsity pattern.
58 *
59 * This class implements the finite-volume 3/5/7 pt stencil specific generation
60 * of sparsity patterns from a given unstructured mesh.
61 *
62 * For an internal face f with owner P and neighbour N (P < N by construction):
63 * ownerOffset[f] = offset within row P for column N → A[P, N] (upper triangular)
64 * neighbourOffset[f] = offset within row N for column P → A[N, P] (lower triangular)
65 */
