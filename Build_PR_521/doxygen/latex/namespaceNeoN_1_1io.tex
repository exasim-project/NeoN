Read an \doxylink{classNeoN_1_1UnstructuredMesh}{Unstructured\+Mesh} from a VTM (VTK multiblock) file. 

The VTM file must follow the layout produced by \doxylink{namespaceNeoN}{NeoN}\textquotesingle{}s VTM writer\+:
\begin{DoxyItemize}
\item Block 0 ("{}internal\+Mesh"{})\+: vtk\+Unstructured\+Grid with all volume cells.
\item Block 1 ("{}boundary"{})\+: nested vtk\+Multi\+Block\+Data\+Set whose sub-\/blocks are named vtk\+Poly\+Data patches.
\end{DoxyItemize}

Connectivity and geometry are reconstructed from the volume cells. Boundary faces are matched to their originating patch by comparing sorted face-\/node sets, so patch names and per-\/patch offsets are preserved.

Patch names and face-\/to-\/node connectivity are stored in the mesh stencil\+DB under the keys {\ttfamily io\+::patch\+Names} and {\ttfamily io\+::face\+Nodes} respectively, allowing a lossless write-\/back via the VTM writer.
