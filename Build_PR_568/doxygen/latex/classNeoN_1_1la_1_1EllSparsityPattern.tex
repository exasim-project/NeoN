\subsubsection*{template$<$typename Index\+Type$>$\newline
class Neo\+N\+::la\+::\+Ell\+Sparsity\+Pattern$<$ Index\+Type $>$}
fixed-\/width, padded column-\/index representation of a matrix (ELLPACK format) 

Every row reserves {\ttfamily \doxylink{classNeoN_1_1la_1_1EllSparsityPattern_a79352612b79ac543ef5552180ea3a7b0}{num\+Stored\+Elements\+Per\+Row()}} column-\/index slots, the width of the widest row in the matrix. Rows with fewer nonzeros are padded with {\ttfamily \doxylink{structNeoN_1_1la_1_1EllSparsityView}{Ell\+Sparsity\+View}\texorpdfstring{$<$}{<}Index\+Type\texorpdfstring{$>$}{>}::invalid\+Index()}. Slots are stored column-\/major, i.\+e. slot {\ttfamily s} of row {\ttfamily i} is stored at {\ttfamily i + \doxylink{classNeoN_1_1la_1_1EllSparsityPattern_a612112caa329c21077141cd9bef000c2}{stride()} \texorpdfstring{$\ast$}{*} s}, so that a one-\/thread-\/per-\/row kernel reads/writes memory in a coalesced fashion when iterating over slots.
