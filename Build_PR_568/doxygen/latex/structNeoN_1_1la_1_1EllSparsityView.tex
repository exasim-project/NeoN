\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Index\+Type$>$\newline
struct Neo\+N\+::la\+::\+Ell\+Sparsity\+View$<$ Index\+Type $>$}
\doxylink{classA}{A} view struct to allow easy read/write on all executors for the ELLPACK (fixed-\/width, padded) sparsity pattern. 

Column indices are stored column-\/major across the padded row slots, i.\+e. slot {\ttfamily s} of row {\ttfamily i} lives at flat offset {\ttfamily i + stride \texorpdfstring{$\ast$}{*} s}. Rows with fewer nonzeros than {\ttfamily num\+Stored\+Elements\+Per\+Row} are padded with {\ttfamily \doxylink{structNeoN_1_1la_1_1EllSparsityView_ade7595799f2b0ed3da6d82fb98b1e243}{invalid\+Index()}}.
