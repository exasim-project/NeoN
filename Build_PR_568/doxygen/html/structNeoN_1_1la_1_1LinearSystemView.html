Detailed Description

template<typename RHSValueType, typename SystemMatrixViewType, typename BoundaryMatrixViewType>
struct NeoN::la::LinearSystemView< RHSValueType, SystemMatrixViewType, BoundaryMatrixViewType >

A view linear into a linear system's data.

Template Parameters
RHSValueTypeThe value type of the rhs/solution vectors.
SystemMatrixViewTypeThe type representing the system matrix view.
BoundaryMatrixViewTypeThe type representing the boundary matrix view. Independent of SystemMatrixViewType since the two matrices may use different sparsity formats (e.g. an ELL system matrix with a COO boundary matrix).
