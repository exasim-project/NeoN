Detailed Description

Accumulates references to VolumeFields for a single write pass.

Building VTK topology is expensive. FieldSet lets you add multiple fields and write them all in one pass (one topology build, multiple AddArray calls).

Example:

NeoN::io::FieldSet fs;
fs.add(pressure).add(velocity);
NeoN::io::writeVtm(mesh, fs, "output.vtm");
