\doxysubsection{Detailed Description}
Accumulates references to Volume\+Fields for a single write pass. 

Building VTK topology is expensive. \doxylink{classNeoN_1_1io_1_1FieldSet}{Field\+Set} lets you add multiple fields and write them all in one pass (one topology build, multiple Add\+Array calls).
